    How it works. A small set of English-language rules checks for prize claims, credential requests, payment demands, urgency, and other common patterns. Each signal adds points: 0–1 = few signals, 2–4 = closer look, 5+ = likely spam. Points are not a probability or measured accuracy. Context, other languages, and new tricks can be missed; legitimate messages can also be flagged.
